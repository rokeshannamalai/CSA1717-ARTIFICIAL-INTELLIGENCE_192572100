# Integrated Experiments – Machine Learning & Reinforcement Learning

## Experiments
1. Decision Tree Classification using the Iris dataset and Gini Index.
2. Q-Learning on a 4×4 Grid World.

## Requirements
```bash
pip install numpy pandas matplotlib scikit-learn pillow reportlab
```

## Run
```bash
python Python_Code.py
```

The program generates `decision_tree.png`, `q_learning_reward.png`, and `Output.png`.
