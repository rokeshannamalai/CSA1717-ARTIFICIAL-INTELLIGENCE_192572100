# Artificial Intelligence Lab Assessment

## Title
Implementation of A* Search Algorithm and Minimax Algorithm with Alpha-Beta Pruning

## Description
This assessment implements two Artificial Intelligence algorithms in Python:
- A* Search Algorithm
- Minimax Algorithm with Alpha-Beta Pruning

Both programs demonstrate step-by-step execution with user input and iteration-wise output.

## Features

### Question 1: A* Search
- Finds the shortest path between the start and goal nodes.
- Displays Current Node, Open List, Closed List, g(n), h(n), and f(n).
- Calculates the optimal path and total path cost.

### Question 2: Minimax with Alpha-Beta Pruning
- Evaluates the game tree using the Minimax algorithm.
- Displays Alpha (α), Beta (β), selected values, and pruned nodes.
- Determines the best move and final minimax value.

## Requirements
- Python 3.x
- Modules Used: `heapq`, `math`

## How to Run
1. Run the Python program.
2. Select the desired algorithm.
3. Enter the required inputs.
4. View the iteration-wise execution and final result.

## Learning Outcome
This assessment helps understand informed search using A* Search and adversarial search using Minimax with Alpha-Beta Pruning, along with their practical implementation in Python.
